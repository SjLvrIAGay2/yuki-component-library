# 快速开始

## 构建并安装

准备 Node.js 22.13 或更高版本。在此仓库根目录安装依赖、构建并打包。

```bash
npm ci
npm run build:lib
npm pack -w @yuki-ui/react
```

在使用组件库的 React 项目中安装上一步生成的文件。将示例路径替换为本地 tarball 的实际路径。React 与 React DOM 的 peer 版本范围均为 `^18.3.0 || ^19.0.0`。

```bash
npm install /path/to/yuki-ui-react-0.1.0.tgz
```

## 引入样式

在应用入口引入一次完整样式，它包含设计令牌、基础样式和组件样式。

```tsx
import '@yuki-ui/react/styles.css';
```

只在自有组件中复用颜色、间距等 CSS 变量时，可以单独引入 `@yuki-ui/react/tokens.css`。

## 创建第一份表单

ConfigProvider 为子树配置语言、主题和默认尺寸。下面的表单收集项目名称，提交成功后显示名称。输入框的标签通过 Form.Item 与实际控件关联。

```tsx
import { useState } from 'react';
import { Button, Card, ConfigProvider, Form, Input } from '@yuki-ui/react';

export default function FirstScreen() {
  const [created, setCreated] = useState('');
  return (
    <ConfigProvider theme={{ mode: 'system' }} locale="zh-CN">
      <Card title="创建项目">
        <Form<{ name: string }> layout="vertical" initialValues={{ name: '' }}
          onFinish={({ name }) => setCreated(name.trim())}>
          <Form.Item name="name" label="项目名称"
            rules={[{ required: true, whitespace: true, message: '请填写项目名称' }]}>
            <Input placeholder="冬季发布" />
          </Form.Item>
          <Button type="submit">创建</Button>
        </Form>
        {created && <p role="status">已创建项目：{created}</p>}
      </Card>
    </ConfigProvider>
  );
}
```

## 导入组件和查看参考

从包根具名导入组件或类型，也可以使用 `import { Button } from '@yuki-ui/react/components/button'` 这样的子路径。两种方式均使用前述样式入口。

安装包附带覆盖全部公开组件的 AI 指南。在使用组件的项目目录中执行下列命令可以定位 Markdown 文件。

```bash
node -p "require.resolve('@yuki-ui/react/ai-guide.md')"
```

文档站中的令牌页列出了颜色、字号、间距和动效的取值。[设计令牌](#/tokens)
