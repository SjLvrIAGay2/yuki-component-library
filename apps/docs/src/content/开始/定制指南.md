# 定制指南

## 调整主题和间距

用 `ConfigProvider.theme.primaryColor` 设置品牌色。组件会据此派生悬停色、按下色、浅色表面、边框和焦点环。`theme.tokens` 可按名覆盖已有的令牌。嵌套 Provider 也会为子树内的弹层提供相应的挂载点。

```tsx
import { Button, ConfigProvider } from '@yuki-ui/react';

export function LocalBrand() {
  return (
    <ConfigProvider global={false} theme={{
      primaryColor: 'var(--yuki-emerald-500)',
      tokens: { 'radius-md': 'var(--yuki-radius-lg)' },
    }}>
      <Button>保存</Button>
    </ConfigProvider>
  );
}
```

普通 CSS 中也可直接引用令牌，配合主题切换处理颜色和间距。

```css
.checkout-summary {
  padding: var(--yuki-space-6);
  color: var(--yuki-color-text-secondary);
}
```

## 定制组件部位

支持 `classNames` 和 `styles` 的组件分别列出具名部位。Modal 的 header 和 body 可独立定制；Dialog 的标题、描述和正文则分别通过 titleProps、descriptionProps 和 bodyProps 接收原生属性。

```tsx
import { Modal } from '@yuki-ui/react';

export function ReleaseModal({ open, onOpenChange }: {
  open: boolean;
  onOpenChange: (open: boolean) => void;
}) {
  return <Modal open={open} onOpenChange={onOpenChange} title="发布版本"
    classNames={{ header: 'release-header' }}
    styles={{ body: { padding: 'var(--yuki-space-6)' } }}>确定发布当前版本？</Modal>;
}
```

## 替换内容与操作

- Table 的 `columns[].render(context)` 定制一列，表级 `renderCell(context)` 为缺少列级渲染函数的单元格提供回退。展开行使用 `expandable.expandedRowRender(row, rowIndex)`，空表使用 `empty` 节点或无参函数。
- Select 的 `renderOption(option, state)` 返回选项内容，可读取 `state.selected`、`state.active` 和 `state.disabled`。标签是 JSX 时用选项的 `textValue` 提供可搜索文字。
- Menu 的 `items[].label` 和 Tour 的 `steps[].title`、`description`、`cover` 都接收 React 节点。
- Empty 的 `image` 放插图，`children` 放操作按钮。Modal 的 `footer` 可传自定义按钮区或 null。

## 尺寸、色调与动效

按钮的 `variant` 决定表面样式，`tone` 决定语义色。例如 `<Button variant="outline" tone="danger">移除</Button>`。支持全局尺寸的控件优先使用实例的 size，其次读取 ConfigProvider.size。全局 `motion={false}`、系统减少动效偏好和组件自身的 animation 配置用于调整动效。

## 受控与非受控

Tabs 组合模式中，标签和面板通过相同的 value 配对。受控时在 onChange 中写回当前值，非受控时可以省略状态和回调，给 Tabs 传 `defaultValue="summary"`。

```tsx
import { useState } from 'react';
import { Tabs, TabsContent, TabsList, TabsTrigger } from '@yuki-ui/react';

export function ProjectTabs() {
  const [tab, setTab] = useState('summary');
  return (
    <Tabs value={tab} onChange={setTab}>
      <TabsList aria-label="项目详情">
        <TabsTrigger value="summary">概览</TabsTrigger>
        <TabsTrigger value="history">历史</TabsTrigger>
      </TabsList>
      <TabsContent value="summary">项目概览</TabsContent>
      <TabsContent value="history">暂无变更记录</TabsContent>
    </Tabs>
  );
}
```

## 自定义表单控件与 ref

原生属性和 ref 的目标由组件类型决定。例如 Input 的 ref 指向输入元素，`fieldProps` 作用于独立字段的包装层。在命名的 Form.Item 内接入自定义输入时，可用 useFieldControl 取得字段状态和可访问属性，向实际控件传递 id、disabled、ariaProps，并转发值变化和失焦。

```tsx
import { Form, useFieldControl } from '@yuki-ui/react';

function ProjectName() {
  const field = useFieldControl<string>();
  return <input id={field.id} {...field.ariaProps} disabled={field.disabled}
    value={field.value ?? ''} onChange={e => field.onChange?.(e.currentTarget.value)}
    onBlur={field.onBlur} />;
}

export function ProjectForm() {
  return <Form><Form.Item name="name" label="项目名"><ProjectName /></Form.Item></Form>;
}
```
